# Save editor - in-game verification checklist (game as oracle)

*Rewritten 2026-10-02. The 2026-07 table asked the game seven questions through saves whose edits
landed on the wrong record (the editor's inventory frame was 32 bytes late, see
[SAVE-EDITOR-STATUS-2026-10-02.md](SAVE-EDITOR-STATUS-2026-10-02.md)); none of those answers count.
The probes below are generated by `i76-calibration-saves.py` on the corrected frame, each edit
verified by `i76-save-editor.py --check` before it leaves the staging folder. Screenshots are ground
truth. Report results as-is, including "nothing visible".*

## Generate and install

```
# build on the sandbox's own save set, write into a staging folder (never into the game folder)
python i76-calibration-saves.py --game C:\Users\james\i76-uncap-lab\game --staging C:\Users\james\i76-uncap-lab\cal-staging
python i76-save-editor.py --dir C:\Users\james\i76-uncap-lab\cal-staging --check     # every probe: round-trip OK, no warnings
```

Then, with no `i76*` process running: back up the sandbox set (`leg-b.ps1` does this itself into
`save-backup-<ts>\` with md5s), copy every file from the staging folder into
`C:\Users\james\i76-uncap-lab\game` (the probes are new slots; the staged `savegame.dir` is the
sandbox's directory with the probe records appended, byte for byte), and load each probe with

```
powershell -ExecutionPolicy Bypass -File autotest\saves\leg-b.ps1 -WantFile saveNNN -WantRow k -StopAtGarage
```

`CAL-MANIFEST.md` in the staging folder lists slot, board row `k`, the exact edit, the expected
reading and the md5 of every file. The slots below are the ones the script picks on today's lab set
(9 records -> probes in save009..save016); re-read the manifest if the set changed. **Never** on the
daily-driver install.
