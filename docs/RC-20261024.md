**Row 4, three harness faults (none in the build):**
1. **Hang.** Under the Start-Process runner, row 4 stalled after leg-b reached the garage. This happened at 06:22 and 06:33 here,
   and also in Scott's 16:07 / 20:44 TIMEOUTs. The cause is tick-av's known deadlock: orphaned `mute-proc.ps1 -Watch` watchers
   hold gate-folder's `cmd /c` output pipe. Fixed with `tools\twin-reaper.ps1`, the tick-av reaper aimed at the twin. It ended 2
   watchers at 06:59 and the row then ran to the end.
2. **False FAIL on the F2 shell.** gate-folder recognised the save screen only by "slot -1 with a bookmark list". F2 removes exactly
   that reset (OTL item 48: "F2 opens the Save screen at slot 0"). The 06:58 run therefore read slot 0 with the list freshly
   allocated (0x145bf248) and failed "Save Bookmark screen up". gate-folder.ps1 now also accepts a list that the click allocated
   (lab `572bd91`). **Row 4 has not been re-run since that fix.**
3. Two interrupted runs left a scratch `save018` / `save019.cmp` and the scratch savegame.dir record on the twin. They were put back
   from the RC by md5 (35 state files equal to the RC; the twin's input.map is the staged one).

## 5. LAN: kept separate (compatibility with the Macs)

The Macs' Gold apps run proxy 0ce90a90 (cf4f81da + the Mac Esc fix) with the 2026-10-20 polish pack's arena files
(MAC-CONVERGE-2026-10-20, LAN-MATRIX-2026-10-20). The PC's pack `Games\I76\lan` runs cf4f81da and is byte-identical in the files

instead, which was not modified. The pack's own launcher takes no arguments.
