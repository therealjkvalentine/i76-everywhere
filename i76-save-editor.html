Where do the save files live? What do the fields mean?

Easiest: run i76-save-editor.command (or python3 i76-save-editor-server.py [--dir DIR]) from the repo — it opens this page with your saves already on the order pad and lets Save Bookmark write straight back to the game folder (one-time .pre-edit backups). Without it, drag the files in from:

  • Mac (this repo's wrapper): ~/Applications/Sikarugir/Interstate 76 - Software (DxWnd).app/Contents/SharedSupport/prefix/drive_c/GOG Games/Interstate 76/
  • Windows (GOG): next to i76.exe (e.g. C:\GOG Games\Interstate 76\)
  • Steam Deck (Heroic): the game folder inside the install path

In drag-and-drop mode, downloads replace the originals by hand. "Save as" a new slot also downloads an updated savegame.dir — copy both in, or the LOAD screen won't list the new slot.

Format notes (reverse-engineered, see the repo docs): the save holds the car (equipped parts, armor in tenths, exactly as the DEFENSE panel shows), the van inventory (spare parts — the game marks these (V)), and a trailing section, the repair order (R), which is copies of the (R) parts and is rebuilt from them when you save. Ammo is never stored — bookmarks happen at the shack, weapons refill from their spec. Each part carries a state — (C) mounted on the car, one per equipped slot, (V) in the van, (R) on the bench, (S) in field salvage — and condition points vs full condition (the game's highlight is floor(3 × cond ÷ full): red, yellow, green, and none at 100 % — sandbox-measured). The garage keeps only the first 11 car/van/bench weapons in file order; a mounted weapon past that reads Empty, so the page warns and reorders on save. The scene number in savegame.dir: a garage save (state 8) loads that scene, a post-mission save (state 1) plays the next one. Until 2026-10-02 this editor read every part's condition and state from the record AFTER it (and the scene from the next bookmark), so re-check saves edited before then — a scene 0 loads at Scene 1 with the scripted starter loadout, and "Stow spares in van" re-sorts scrambled states. Weapon range and DPS come from Local Ditch's weapons page (community measurements by Greg Schwartz / Zaphod-AVA, in "points of armor" — the same tenths the DEFENSE panel uses); where no measurement exists we show "~N dps spec" computed from the game's own weapon files (damage × salvo × shots/sec ÷ 10, all shots hitting — real DPS runs lower with misses). Flamethrowers are rated the community way: time to destroy a bus. What each part does (the line after every engine, suspension, brake, wheel, weapon and special; hover for the numbers and their sources) comes from the game's own definition files (compnent.cdf, the .wdf/.gdf files) and the reverse-engineered code: offline, for instance, every brake brakes the same and bigger wheels only grip better until the tyre is first hit. Full table: docs/PARTS-REFERENCE.md. Paint Shop rewrites the save's own texture-set reference (the same piranhaN.vtf field the game's car configs use) — the LOAD list's "Stock (Orange)" label is display-only text and stays as-is. Weight is computed (the save stores none): real per-part weights plus the chassis figure found in the vehicle def — flagged until it's calibrated against the in-game GROSS WT.

Glovebox: the classic cheat codes

All work in I'76 and Nitro Riders (source: the I'76 fandom wiki). Hold Ctrl+Shift and type, during play:

  • getdown — level skip (Groove says "get down"; everyone attacks you; die and you restart on the next scene)
  • thirdnostril — bigger radar  ·  wiggleburger — blurry vision
  • with the map up: frflat / flflat / brflat / blflat — deflate that tire
  • Ctrl+Alt+X — self-destruct  ·  F12 on landing — survive a huge fall

Melee-variant names: save a Rattler variant as retpocileh (helicopter), knat (tank); a Phaedra Rattler as hotair (balloon) or thetruthishere (UFO — you saw it crash outside Roswell, after all).
