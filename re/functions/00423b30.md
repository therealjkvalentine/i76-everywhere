## Contract

Opens the MCI CD audio device. Calls 0x470ed0 first (drive scan; returns 0 -> fail 1). Then MCI_SYSINFO (0x810)
with MCI_SYSINFO_QUANTITY (0x100) and wDeviceType 0x204 (MCI_DEVTYPE_CD_AUDIO), MCI_SYSINFO_NAME (0x400) into a
32-byte buffer (mciGetErrorStringA on failure), then MCI_OPEN (0x803) with MCI_OPEN_TYPE (0x2000) using that name.
On open failure the MCI error is stored in 0x524678 and 1 is returned. On success the device id is stored in
0x4ed890 and MCI_SET (0x80d) MCI_SET_TIME_FORMAT (0x400) with format 10 (MCI_FORMAT_TMSF) is sent; if that fails
the device is closed (MCI_CLOSE 0x804), 0x4ed890 = -1 and 1 is returned. Finally it walks auxGetNumDevs /
auxGetDevCapsA looking for wTechnology 1 (AUXCAPS_CDAUDIO), falling back to 2 (AUXCAPS_AUXIN), and stores the
found aux index (or -1) in 0x4ed894; returns 0. The only caller 0x423d50 feeds 0x4ed894 to auxSetVolume.
The bytes at 0x423b9a (mov al,1; nop; nop; jle) look like a patched quantity check in the reference image.

- hypothesis: returns 0 on success and 1 on failure (caller 0x423d50 treats 0 as success)
