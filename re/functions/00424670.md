## Contract

Plays one CD audio track through MCI. If the cdaudio-active flag [0x524674] is clear it returns at once. It takes
one int (the track number, read at 0x424684 as [esp+0x34]); the "to" track is track+1 (clamped to 1 when the
argument is < 1). It sends MCI_STATUS (0x814) with MCI_STATUS_ITEM (0x100) and item 4 (MCI_STATUS_MODE) on the
device id [0x4ed890]; on failure it closes the device (MCI_CLOSE 0x804), sets the id to -1 and clears the active
flag. The mode result is mapped to a small state code (the jump tables at 0x42470c and 0x42492f are nop'd in this
image, so the state is forced to 2). If the track lies within [first,last] ([0x524588], [0x52458c], a table
filled by 0x4249a0 from MCI_STATUS_NUMBER_OF_TRACKS / MCI_STATUS_POSITION+MCI_TRACK), it sends MCI_PLAY (0x806)
with MCI_FROM (4) = positions[track - first] and, when positions[track+1 - first] is non-zero, MCI_TO (flags 0xc).
In state 3 it first sends MCI_STOP (0x808); in state 4 it also records the track in [0x524660] and zeroes
[0x524664]/[0x524668] (the TMSF minute/second bytes that 0x423d50 unpacks). Returns the MCI error of the last
command (or 0). Both callers (shell_cb_20 0x423330 and 0x423400) pass the music track number and clean up 4 bytes.
