## Contract

Parses an 8-byte name passed by value on the stack (the caller pushes two dwords loaded from the 16-entry slot
table at 0x541090 + i*0x48) with sscanf("nvcl%1x.vcf"); when a hex digit is recovered it clears bit (digit & 31)
in the dword at bss 0x5419b8. The sibling 0x455de0 (same TU, same format string) creates the nvcl0..f.vcf files
and zeroes the same dword, so 0x5419b8 is a per-nvcl-file bitmask. The only caller 0x454340 is the dp* player
removal routine (dpGetPlayerName / dpSetPlayerData, "%s is now the host!"), which calls this when the removed
slot's name field is non-zero. The name says only what the body does: clear the nvcl bit.

## Hypotheses

- hypothesis: The two dwords pushed by the caller at 0x4545c7/0x4545c8 are an 8-byte name field of the 16-slot player table 0x541070 (stride 0x48); the function reads it as a string through sscanf, so the by-value char[8] shape rests on the caller only.
- hypothesis: 0x5419b8 marks which nvcl0..f.vcf slot files are in use by network players; clearing a bit frees a slot when a player leaves (inferred from caller 0x454340 and sibling 0x455de0, not from this body).
