## Contract

Returns 0 for a NULL or empty name. Otherwise builds a path in the bss buffer 0x5a7cd8: when cd_GetDriveLetter
(0x470d30) returns non-zero it copies " :\cutscene\" (0x4fe294) and overwrites byte 0 with the drive letter,
else it copies the 5-byte prefix at 0x4fe28c (bytes "smk\" per disasm annotation; not a strings.tsv row). It
appends param_1 (strcat-style repne scasb / rep movs) and calls MSVCRT _stat through ebp. If the stat fails and
a CD drive is set and param_2 != 0, it retries with the smk\ prefix. Returns 1 when a stat succeeded and either
param_2 == 0 or param_2 equals the stat buffer dword at [esp+0x28] (offset 0x14 of the 0x24-byte local, which is
st_size in MSVC struct _stat). Callers: 0x4122d0 (per-entry 0x54-byte records, whose strings include
"%s does not exists on the cd or the smk directory") and shell_cb_17 0x470f90 with "int12f01.smk", both with
param_2 = 0.

## Hypotheses

- hypothesis: param_2 is an expected file size compared with st_size (stack 0x28 after 0x10 of pushes = local+0x14); no caller passes non-zero in the two call sites read.
- hypothesis: 0x4fe28c holds the smk directory prefix (disasm annotation) and the buffer at 0x5a7cd8 is a path buffer of at least 13 bytes plus the appended name.
- hypothesis: Both callers deal with .smk movie files (int12f01.smk, and the 'smk directory' message in 0x4122d0), so the words Smk/Exists come from the path prefixes plus _stat.
