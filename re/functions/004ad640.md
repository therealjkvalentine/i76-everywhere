## Contract

Takes an 8-byte packed name passed by value as two dwords (param_1, param_2), clears a 16-byte static bss buffer at
0x5dabb0, strncpy's the 8 bytes into it, and returns NULL if the name equals the literal "null" (_stricmp against
init 0x4c3280) or is empty. Otherwise it masks every one of the 8 bytes to 7 bits (and 0x7f), terminates at byte 8,
appends the optional string param_3 (strlen/strcat idiom via repne scasb / rep movs) and returns the static buffer.
Callers pass file extensions as param_3: ".geo" (0x4fe724, from anchored bwd2_h_SOBJ_4b8470), ".vcf" (0x4c2020, net
callers 0x452e30/0x456220/0x455e60), ".wdf"/".gdf" (salvage 0x4b1610), so the result is a file name built from an
8-character resource name plus extension. It sits in the bwd2 handler TU (neighbours 0x4ad950.. are bwd2_h_*).
