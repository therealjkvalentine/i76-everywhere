## Contract

Redraft after the G4 name requeue. If the CD audio open flag 0x524674 (globals.tsv mci_cdaudio_active) is zero,
it returns 0. Otherwise it issues mciSendCommandA([0x4ed890], 0x814 MCI_STATUS, 0x100 MCI_STATUS_ITEM, &p) with
dwItem = 4 (0x424573/0x424584). On success the returned value is mapped through the jump table 0x424658
(index = value - 0x20d, bounds check `cmp eax,5; ja` at 0x42462f) to a small code 1..5 (0x20d -> 2, 0x20e -> 3,
0x211 -> 4, 0x212 -> 1, else 5). On MCI failure it closes the device (0x804 MCI_CLOSE at 0x4245ad), sets the
device id to -1 and the open flag to 0, and uses code 5. If the code equals the stored code in 0x524670 it
returns 0. On a stored-1 -> new-2 transition it calls 0x4249a0(0x524588) up to three times with _putch(7) after
each nonzero result and returns 0 without storing if all three fail. Otherwise it writes the code to 0x524670
and returns 1. Name words: the in-function actions are an MCI_STATUS query of the CD audio device plus a
conditional store of the result into a global (Update); the periodic calling is caller context, and "Mode" is
more specific than the MCI_STATUS command itself, so this view uses Update + CdAudio + Status.
