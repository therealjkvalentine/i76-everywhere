## Contract

Walks drive indices 0..25 (cmp ebx,0x1a at 0x470f75). For each index whose byte in cdrom_drive_flags (0x609520) is
non-zero it builds a root path "<letter>:\" (letter = index + 'A', template dword at 0x4f8bac " :\\"), increments
the counter at 0x58d930, and calls KERNEL32!GetVolumeInformationA with the volume-name buffer 0x609540 (32 bytes).
On success it compares the label with MSVCRT!_strnicmp against the literal at 0x4f8bdc ("I76_CD2", length from
repne scasb) and stops at the first match. It returns the counter: the 1-based ordinal of the matching CD drive
among flagged drives, or the number of flagged drives when none matches (0 when no CD drive is flagged). Its only
caller sound_OpenCdAudio (0x423b30) returns early when the result is 0. No stack parameters; plain `ret`.
