## Contract

Gated on render_gate_flags == 1 and a nonzero bss:0x54b67c. Reads the clip rectangle of the surface object at
param_1+0x3c (+0x1c..+0x28) to get width/height. If they differ from the cached 13-dword image descriptor at
bss:0x54b648, it frees the old descriptor (0x474d40), loads a resource named from the 13-byte-stride name table
init:0x4f7c98 indexed by bss:0x5dd360 (0x46ffc0; the pristine bytes at that table read bmask160.msk, bmask128.msk,
bmask102.msk, bmask800.msk, bmask640.msk), allocates a width x height 8-bit buffer from the per-index size table
init:0x4f9e14/0x4f9e18 (0x474c60), expands the resource's 15-bit run list into it (bit 0x8000 runs filled with
0xfe), then re-encodes each row as signed 16-bit run lengths (positive = 0xfe/transparent run, negative = opaque
run), copies that into a new descriptor (0x474c60, 0x474e00, memmove) and stores it at bss:0x54b648, then releases
the resource (0x46fd40). Every call then walks the run list at bss:0x54b65c (descriptor +0x14) over the surface
rows (surface +0x14 = pixels, +0x0 = pitch): positive runs are filled with 0xff bytes when 0x495060 returns false
(8 bpp) or with the 16-bit value bss:0x60865e when it returns true (2 bytes per pixel); negative runs are skipped.
So it paints a cached mask over the frame buffer. WinMain calls it with 0x4c2730 between the two present
callbacks.
