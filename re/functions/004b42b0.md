## Contract

Loads the mission file named by its only argument (called once, from WinMain 0x402b30 at 0x4034f4). Calls
0x4b84e0, copies at most 16 bytes of the name to a local, _splitpath's it and lowercases it. Sets 0x6562c4 = 0 and
0x6562c0 = 0x27; if the base name is exactly 4 characters and the extension equals '.msn' (0x500678, _stricmp at
0x4b4342), 0x6562c0 = atol(base+1) and, when that is > 0, 0x6562c4 is set from the base's first letter
(m/n -> 1, t -> 2, s/p -> 3). If the name has no extension, '.msn' is appended. The name is resolved through
0x4b2d50 (ZIX/path lookup, returns a static path buffer 0x5dabc8); a null result reports 'Cannot locate Mission
file %s in ZIX. Exiting' through 0x42d5d0. The resolved path is split again and its drive letter is compared
(toupper) with 0x470d30's letter; if equal shell_cb_21 is called. A name starting with 'null' counts as success
without loading. Otherwise the file is opened via 0x46ffc0 (pointer stored in 0x5db97c), 0x46fee0 gives its size
and 0x5db980 = base + size (end pointer), then bwd2_Parse walks it with tag table 'BWD2' (0x500328, 2 entries) and,
if that succeeds, 'WDEF' (0x500348, 7 entries), each time storing the result in 0x5db97c; 0x46fd40 releases the
name. Failure reports 'Mission file %s not found. Exiting' with the caller's argument. Always returns 1.

## Hypotheses

- hypothesis: 0x6562c0 (default 0x27, else the number in names like m01.msn) is the mission/level number and 0x6562c4 a mission class from the first letter (m/n=1, t=2, s/p=3); letter meanings are not evidenced in this function.
- hypothesis: The existing functions.tsv row calls this mission_LoadFile; 'mission' is not a canonical prefix, so bwd2 (the subsystem of that row and of bwd2_Parse) is used.
- hypothesis: The shell_cb_21 call when the resolved drive equals the CD drive letter (0x470d30) plausibly marks a CD-resident mission; not evidenced further here.
