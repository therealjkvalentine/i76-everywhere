## Contract

Takes a table of font-descriptor pointers (param_1), selects slot [0x654b80] & 0xff, returns NULL if that slot
is empty. The descriptor's +0 is a face-name pointer (falls back to param_1[0] when NULL) and +4 is the height.
It fills a LOGFONTA on the stack (width/escapement/orientation 0, weight 100, OUT_TT_PRECIS 4, PROOF_QUALITY 2),
copies the face name into lfFaceName, sets lfCharSet to 0x80 (SHIFTJIS_CHARSET) when *[0x4fe194] == 3, gets a DC
through the function pointer [0x5dd2d0] (0x5dcec0), calls SetMapperFlags(hdc, 1), CreateFontIndirectA(&lf),
releases the DC through [0x5dd2d4] (0x5dcec0) and returns the HFONT. Both callers (0x4953e0, 0x45e2b0) store the
result as an HFONT and clean one argument with add esp,4.

## Hypotheses

- hypothesis: 0x654b80 (bss, read 4 bytes at 0x4768f0, masked to a byte at 0x4768f9) is a language/variant index selecting the descriptor slot; no naming evidence.
- hypothesis: 0x4fe194 (init) points at an int whose value 3 means a Japanese language setting, since it selects SHIFTJIS_CHARSET (0x80) at 0x476996.
- hypothesis: [0x5dd2d0]/[0x5dd2d4] with 0x5dcec0 look like a renderer surface GetDC/ReleaseDC pair (0x5dd2c4 is called with the same object in caller 0x4953e0).
